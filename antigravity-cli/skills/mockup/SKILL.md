# Mockup
1. Leia DESIGN.md e docs/01-requisitos. Se o DESIGN.md não existir, sugira /design-brief primeiro.
2. Pergunte: qual tela, qual o objetivo do usuário nela, qual a ação principal, em que dispositivo ela é mais usada.
3. Faça primeiro um wireframe simples (cinza, só estrutura) e espere minha aprovação. Depois a versão com o DESIGN.md.
4. Grave um arquivo HTML autocontido por tela em docs/05-design/mockups/ (CSS no mesmo arquivo, tokens do DESIGN.md como variáveis CSS). Inclua os estados vazio, carregando e erro.
5. Se o MCP chrome-devtools estiver ativo, abra o arquivo, tire uma captura em tela de celular e de desktop e aponte problemas de contraste, alinhamento e hierarquia.
6. Aponte 3 decisões de UX que eu devo questionar nesta tela.
