# Direção visual a partir de referências
1. Olhe cada imagem anexada. Para cada uma, pergunte o que eu gosto nela e o que NÃO quero copiar. Não presuma.
2. Descreva o que vê, de forma objetiva: cores (com hex aproximado), tipografia (estilo, peso), espaçamento, cantos, sombras, densidade de informação, tom (sério, leve, técnico).
3. Proponha 2-3 direções diferentes entre si, com prós e contras para o meu público (leia docs/00-discovery). Pare e espere minha escolha.
4. Só depois grave DESIGN.md na raiz do projeto: tokens (cores, tipografia, espaçamento, raio, sombras), regras de uso, estados (vazio, carregando, erro, sucesso) e regras de acessibilidade (contraste mínimo 4,5:1, foco visível, navegação por teclado).
5. Não copie telas inteiras nem marcas das referências; extraia princípios.
